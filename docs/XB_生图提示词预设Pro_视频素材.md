## 三、口播要点（照着讲即可）

1. **痛点**：以前要 5 个节点串起来（模型加载器 + 推理参数 + API 设置 + 提示词增强预设 + 指令推理），线连一堆，参数找不到。
2. **现在**：一个节点三件事 —— 拼提示词、配空latent、上 AI。
3. **拼提示词**：8 大类 500+ 中英双语词条，点一下就成句；每个词条还能写补充描述；可以自建专属词条。
4. **配画布**：9 种主流模型的空latent，通道 / 下采样 / 步长 / 尺寸 / batch 上限全部按官方对齐，选模型就行。
5. **上 AI**：本地 llama-cpp 或在线 API；图 → 提示词；**图 + 你的要求 = 看图改图**（先识图再按要求改，只输出修改后的最终画面，不会写成「原本…被替换为…」）。
6. **预设模式**：常规文生图 / 人物三视图 / 四视图 / 五视图 / 背景纯透明，设定词自动置顶，还能自己改、换模式不丢。
7. **细节**：语言只设一处；思考过程自动过滤；所有选项收在三个弹窗里，节点表面干干净净；配置随工作流保存。
8. **收尾**：安装方式 + 一句号召 —— 「节点已经开源，链接在简介，用起来有问题评论区告诉我」。
